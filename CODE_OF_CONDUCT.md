# Code of Conduct

## Standards

This is a personal repository shared for reference. Anyone interacting with it through issues,
pull requests or discussions is expected to be respectful and constructive, give specific
feedback rather than vague criticism and assume good faith when something looks unusual.

## Unacceptable behaviour

Harassment, abuse or personal attacks of any kind, spam or off-topic promotion, sharing anyone's
private information without consent.

## Enforcement

> [!NOTE]
> Report unacceptable behaviour to [contact@isaacadjei.me](mailto:contact@isaacadjei.me) or via
> [isaacadjei.me/contact](https://isaacadjei.me/contact). I'll review reports and take
> appropriate action, including removing comments or blocking users if necessary.
