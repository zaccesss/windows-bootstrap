# Security Policy

## Scope

Security issues in scope for this repository:

- Accidentally committed secrets or credentials
- Unsafe bootstrap behaviour
- Commands that could damage or compromise a target system
- Insecure handling of downloaded software or external repositories

## Out of scope

- GitHub itself - report platform issues to GitHub directly
- Third-party packages the bootstrap installs, best raised with that project directly

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email [contact@isaacadjei.me](mailto:contact@isaacadjei.me) with details and
> reproduction steps. Expect an acknowledgement within 72 hours.
